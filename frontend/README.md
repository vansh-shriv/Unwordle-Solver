# 🎨 Unwordle Solver Frontend

Next.js 15 Web Application featuring a Cyberpunk Pixel-Glass UI interface for the Unwordle Solver backend logic engine.

## 🧰 Tech Stack

- **Framework**: Next.js 15 (App Router)
- **UI & Styling**: Tailwind CSS, Vanilla CSS custom scanlines & cyber gradients, Google Fonts (`Silkscreen`, `VT323`)
- **State Management**: React `useReducer` for interactive puzzle grid state management
- **Language**: TypeScript

## 🚀 Running Locally

Make sure the FastAPI backend is running on `http://localhost:8000`.

```bash
# Install dependencies
npm install

# Run dev server on port 3001
npm run dev -- -p 3001
```

Open [http://localhost:3001](http://localhost:3001) in your browser.
